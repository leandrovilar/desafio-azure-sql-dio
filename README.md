# Desafio DIO - Configuração de Banco de Dados na Azure

Projeto desenvolvido durante o laboratório da DIO utilizando Microsoft Azure.

---

# 📚 Sobre o Projeto

Este desafio teve como objetivo praticar a criação e configuração de uma instância de Banco de Dados SQL no Microsoft Azure.

Durante o laboratório foram realizados os processos básicos de configuração do banco de dados, servidor SQL e autenticação de acesso.

---

# ☁️ Plataforma Utilizada

- Microsoft Azure
- Azure SQL Database
- GitHub
- Markdown

---

# ⚙️ Etapas Realizadas

- Criação do grupo de recursos
- Criação do servidor SQL
- Configuração do login administrador
- Configuração do banco de dados SQL
- Configuração básica de autenticação

---

# 🖥️ Configuração Utilizada

| Configuração | Valor |
|---|---|
| Serviço | Azure SQL Database |
| Região | Brazil South |
| Nome do Banco | dio-sql-db |
| Nome do Servidor | dio-sql-server2026 |
| Método de Autenticação | SQL Authentication |
